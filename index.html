GUIA DE COMANDOS E COMBATES

PLAYER 1 (PADRÃO / SOLO)

  • A / D : Mover Esquerda / Direita
  • W : Pular
  • S : Agachar
  • A (ou costas) : Bloquear Ataques
  • F : Soco / Garra Rápida (Ataque Leve)
  • G : Chute Pesado (Ataque Forte)
  • H : Golpe Especial / Projétil
  • V ou ESPAÇO : SUPER MOVE (Barra 100%)

PLAYER 2 (VERSUS LOCAL)

  • ◀ / ▶ : Mover Esquerda / Direita
  • ▲ : Pular
  • ▼ : Agachar
  • ▶ (ou costas) : Bloquear Ataques
  • J / Num 1 : Soco / Ataque Leve
  • K / Num 2 : Chute / Ataque Forte
  • L / Num 3 : Golpe Especial
  • P / Enter : SUPER MOVE (Barra 100%)
